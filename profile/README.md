# axismecca : utilities

**Free tools. Built in Queens. Yours to keep.**

</div>

---

axismecca is a creative collective.

Everything in here is a **module**: one small, finished tool that does one job. You download it and run it on your own machine. There is no account, no trial, no server of ours between you and the thing working. Once it is on your computer it is yours.

## Why

It's simple. We're tech enthusiasts. We want to spread our creativity and technology on to you.

## The modules

The first one lands soon. They will be listed here as they ship, numbered in the order they land.

Each module gets its own page with a plain-language setup. If you have never opened a terminal before, start at the top of any module README and it will walk you through it. Nothing here assumes you write code for a living.

## Using them

1. Open the module you want.
2. Follow the setup at the top of its page.
3. Run it.

## Changing them

Every module is released under the MIT license. In plain terms: it is yours. Change it, rename it, strip the parts you do not need, fold it into something you sell.

## What axismecca handles

Websites, branding, photography, video, and live experiences, mostly for small businesses and creatives around New York. That work lives at [axismecca.com](https://axismecca.com).
